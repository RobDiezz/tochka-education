# ТОЧКА — Educational Center Website

Демонстрационный сайт вымышленного образовательного центра, созданный как portfolio project.

## Live Demo

Реальный URL будет добавлен после публикации и проверки GitHub Pages.

## About

Адаптивный одностраничный сайт с программами обучения, фильтрацией, карточками преподавателей, FAQ и демонстрационной формой заявки. Бренд, программы, преподаватели и локация вымышлены; сайт не представляет реальную организацию.

## Features

- Responsive layout
- Program filtering and dialogs
- Mobile navigation
- FAQ accordion
- Accessible keyboard interactions
- Responsive WebP images
- Demo contact form without data submission or storage

## Tech

HTML5 · CSS3 · Vanilla JavaScript

Откройте `index.html` в браузере. Установка зависимостей и сборка не требуются. Оригинальные изображения сохранены в `assets/images/originals/`.
